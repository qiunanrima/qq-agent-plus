# 角色生命系统

从「设置 → 实验功能 → 角色生命系统」开启。点「查看生命状态」可查看运行数据。固化后侧栏出现带脉搏图标的独立入口。关闭实验立即停止后续采集、归纳、提示注入和动机提议，现有记录保留。取消固化同时关闭运行并隐藏导航。

模块按 QQ 对话轮次采集带消息标识的互动。情绪是事件规则和时间衰减的估算值。节律基线取既有睡眠时段；已有精力与心情可用时参与状态计算。近期邀约依会话和参与者隔离，持续三天。现有主动聊天策略决定是否启动会话，动机只在符合条件时贡献一次话题。提议前记录已使用，发送结果未知时不再针对该邀约补发。

生命状态写入安装数据目录的 character-life.sqlite。历史消息无需回填。图谱使用原长期记忆中的实体与关系，按会话查看，并显示每条关系对应的记忆。召回可沿同范围的实体关系走一跳，重新检查归档、到期、遗忘和注入预算。近期事件保留七天，空闲时归纳前几日的互动计数，日归纳保留三十天。空闲时合并同范围内正文及结构化事实完全相同的记忆，保留来源并归档副本。重要记忆获得新独立来源时，由现有遗忘机制巩固；其他记忆按原策略随时间淡化。人格成长在空闲时使用既有模型调度和证据审核，受原有采集配置和预算限制。全量记忆重置会先备份生命状态再一并清理。停用实验即可回退运行行为。
