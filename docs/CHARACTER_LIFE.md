# 角色生命系统

从「设置 → 实验功能 → 角色生命系统」开启。点「查看生命状态」可查看运行数据。固化后侧栏出现带脉搏图标的独立入口。关闭实验立即停止后续采集、归纳、提示注入和动机提议，现有记录保留。取消固化同时关闭运行并隐藏导航。

模块按 QQ 对话轮次采集带消息标识的互动。情绪是事件规则和时间衰减的估算值。节律基线取既有睡眠时段；已有精力与心情可用时参与状态计算。近期邀约依会话和参与者隔离，持续三天。现有主动聊天策略决定是否启动会话，动机只在符合条件时贡献一次话题。提议前记录已使用，发送结果未知时不再针对该邀约补发。

生命状态写入安装数据目录的 character-life.sqlite。历史消息无需回填。关联只记录原记忆 ID，内容经原长期记忆接口读取，并重新检查范围、归档、到期及遗忘条件。近期事件保留七天，空闲时归纳前几日的互动计数，日归纳保留三十天。人格成长依旧使用原有证据审核和采集配置。模块不额外调用模型。全量记忆重置会先备份生命状态再一并清理。停用实验即可回退运行行为。
