# 低频工具按需发现

账号修改、文件、相册、群资料和管理工具通过 `discover_tools` 提供。
常规聊天请求只携带这个入口，不重复携带这些工具的完整参数定义。

1. 调用 `discover_tools({group: "account"})` 查询本轮可用工具和完整参数。
2. 调用 `discover_tools({tool: "set_my_status", args: {...}})` 执行动作。

分类为 `account`、`files`、`albums`、`management`，入口只列本轮有可用工具的分类。
查询本身没有外部写入；查询结果只在当前处理周期内有效，不跨会话缓存。
关闭的功能、当前场景不支持的功能不会进入目录；执行前再次核对平台和管理开关。
技能限制、原工具权限、审批、配额、写入结果未知时禁止重试等规则继续有效。
审计记录保存入口参数，并通过 `resolvedTool` 标记实际执行工具。

统一入口同时适用于 API、Antigravity 和 Codex 的固定 MCP 工具目录，不依赖客户端动态刷新工具表。
首次使用一个分类需要额外一次模型往返；同一周期内可复用查询结果。
普通聊天不调用发现入口，工具定义减少；端到端耗时仍取决于模型服务，不能仅按字符数推断。
