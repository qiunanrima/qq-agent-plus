# 微信官方渠道（实验功能）

模块所有者为 `src/weixin/`，直接使用腾讯 iLink Bot HTTPS 协议，不运行 OpenClaw，
不接管个人微信客户端。协议依据：

- https://github.com/Tencent/openclaw-weixin
- https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md

## 配置与连接

默认 `weixin: { enabled: false, graduated: false }`。设置 → 实验功能 → 微信官方渠道
打开独立页面。固化后入口出现在设置的「平台」菜单；固化不改变启用状态。

1. 获取二维码，用微信扫码并在手机确认；点击「已扫码，检查状态」。如果要求验证码，
   输入手机上显示的验证码后再次检查。二维码五分钟失效；地区跳转只允许官方接口主机。
2. 启用渠道，向微信机器人发一条私聊消息。扫码者默认可聊天；其他联系人只记录发现状态，
   在页面明确允许回复后才能触发模型。启用微信也遵守全局观察/暂停/时间控制。
3. 先验证文本收发，再验证图片。首版不支持普通微信群、好友查询、历史导入、媒体发送；
   语音只接收接口已提供的转写。文件/视频以不支持提示交给模型，不伪装成已理解。

本实现已经过离线模拟验证；首次真实扫码、地区接口和真实收发需要账号所有者现场验收。
不自动扫码、发送测试消息或反复调用模型。

## 模型、权限与共享记忆

- 共享现有全局角色卡、背景，以及可见的 active 人格偏好；不会把其他会话的总结、
  海马原始事件或人物关系证据自动拷入微信。
- 人物记忆在页面填写 QQ 号、确认身份后才共享。只读取该 QQ 用户的长期人物印象，
  包括现有可见的海马人物卡，不读取 QQ 私聊逐条记录。新人物印象以
  `weixin:<account sha256>:<user sha256>` 为来源进入统一人物记忆。
- `hidePrivateInGroup` 同样保护微信来源的私聊记忆；原有 perChat 策略仍生效。
  解除绑定停止之后的跨平台查询和写入，不删除已经共享保存的事实或历史。
- CLI 开启时共用现有模型与全局排队。每个微信会话使用独立聊天键；ACP 可复用进程，
  每轮 MCP 授权、图片与预算独立。不启用 CLI 则使用现有 API 模型。
- 微信默认只允许读取本轮工具返回的图片路径；ACP 图片读取不授予普通文件或命令权限。
  微信联系人原生权限默认关闭，须与全局原生审批同时开启；操作逐次在控制台审批。
  QQ 管理员私聊权限和 QQ 宿主工具审批开关不会自动继承到微信。首版不支持微信私聊审批命令。

## 数据、恢复与回滚

数据在 `data/weixin/state.json`，包含凭据、游标、联系人设置、最近每人 16 条文本上下文、
会话总结、去重记录、最近运行状态和发送台账。目录 0700，文件 0600；状态 API 不返回令牌。
从未启用且未扫码的模块不会创建文件或定时器。停用、解除连接和回滚都不删除聊天或记忆。
解除连接只移除机器人凭据；重新绑定相同账号可继续使用该账号的会话，账号之间不共享上下文。

每条入站在处理前持久去重，过期两分钟的消息不触发回复；发送在请求前记为 unknown，
只有收到成功响应才改为 sent。崩溃/断网后的 unknown 不重发，独立页面显示数量。
服务重启不会自动续跑旧模型请求；运行中请求遗留标为中断。`-14` 暂停该账号一小时，
可重新扫码恢复；收取网络错误按五秒退避，发送不自动重试。

回滚可部署上一提交并关闭 `weixin.enabled`；保留 `data/weixin/`、人物记忆与 QQ 配置。
排障仅查看渠道状态和脱敏记录，不输出 `state.json`、二维码值或原始协议响应。
