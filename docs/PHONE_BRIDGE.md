# 手机接入与个人助理路线图

## 手机通知接入

Agent 使用独立的手机令牌。为 Agent 进程设置 `QQ_AGENT_PHONE_TOKEN`（64 位十六进制随机值），使用现有 HTTPS 入口仅代理 `POST /api/phone-bridge/notifications` 和 `POST /api/phone-bridge/calendar` 到本机控制台服务。地址填写 HTTPS 域名，App 会添加接口路径。令牌通过环境配置传入，勿写入 Git、URL 或日志。更换令牌需要重启 Agent，并在 App 中保存新值。

Android App 的「系统通知 → 连接 Agent」支持编辑并单独保存地址和令牌。「同步通知」上传当前白名单内的本地通知，收到回执后才显示成功。服务端按事件 ID 去重并保留最近 200 条。管理员在 QQ 私聊中明确询问“看看最近的手机通知”时可查询。通知内容只供查询，接入本身不会触发提醒或其他操作。

未设置令牌时接入关闭。回退时移除该环境变量并重启 Agent，已有通知文件保留在数据目录的 `phone-bridge/inbox.json`。

## 自动同步与独立容器

连接页分别控制通知和日程自动同步。白名单通知入库后由 Android 调度联网任务，系统也会安排周期补同步。系统日历在白名单通知入库后读一次，且定期检查，只在内容变化时提交过去 7 天和未来 30 天的只读快照。App 内仍可按任意月份浏览。Android 省电策略可能推迟后台任务，连接页也提供立即同步。服务器用新快照替换旧快照，日历删改会随下一次同步反映；快照记录时区和同步时间。

管理员可以在 QQ 私聊里问「看手机日历，明天的会要准备什么」，并指定容器中的项目目录。Agent 在同一轮可以读取日历，并用 linux_find_workspace_files 在原话明确指定的 /workspace 子目录中按关键词查文件名，最多返回 25 个路径。找到文本候选后，用 linux_read_workspace_material 读取不超过 8 KiB 的摘录，结论可附完整文件路径。日程和通知不会自动写入 /workspace。容器资料查找沿用现有管理员权限和工作区边界；[Gmail 和 QQ 邮箱](PERSONAL_MAIL.md)授权后，Agent 也可以查往来邮件摘录和附件名称，工作区用于处理授权文件和生成交付物。

日程写入要在 App 内授权并选定一个可写日历。管理员私聊明确要求创建一次性日程时，Agent 保存待下发记录。App 在通知触发、定期同步或立即同步时领取，写入后回读并提交回执。状态为已下发但未确认时保留该状态，服务端不会再次发出同一条写入指令。当前后台依赖 Android 调度，锁屏时到达速度受系统调度影响。

新版 App 支持修改选定日历中已同步的单次非全天日程的时间、标题或地点。手机会比对原记录，遇到已被改动或目标不匹配时返回冲突。旧版 App 不会领取修改指令。

开启日程自动同步后，可以在连接页手动启动「实时日程同步」。App 会显示可停止的常驻通知，并等待服务端待办提示。Android 15 及以上对后台数据同步服务有系统时限，模式停止后仍可依赖周期任务和手动同步。

## 后续功能

- **每日秘书与会前准备**。先接一套常用邮箱、小米日历和一个授权项目目录。用会议邀请、邮件线程、参与人和项目名关联资料。给出对方最后一次提出的要求、对应文件、会前还差什么，并附来源。遇到重名项目或多个疑似最新版时列出候选。用一场真实会议验收，随后补定时晨报。
- **邮件委托跟进**。跟踪指定邮件线程，收到回复时提取报价与交期。到期仍未收到回复时起草跟进邮件。
- **个人文件办事**。从邮件附件和授权目录收集票据，去重、核对金额并按模板生成报销单，列出缺票和冲突。
- **日程协调**。结合可用时间和间隔要求拟邀约，核对回复并在用户确认后发日历邀请。

管理员可在 QQ 私聊按应用（如微信、QQ、TIM）、标题或正文关键词及手机通知发布时间筛选通知。旧版 App 同步的记录使用服务端接收时间。结果包含各应用的匹配条数、最近接收时间及截断状态。

开启通知自动同步后，App 的周期任务即使没有待传通知也会报告同步成功。查询结果分别显示最近同步时间和最近收到通知的时间。周期任务仍受 Android 网络和省电调度影响。

内置技能 `personal-briefing` 可在技能设置中为管理员私聊启用，复用手机通知、日历、邮箱和独立工作区的现有访问条件，提供通知汇总和会前准备流程。
