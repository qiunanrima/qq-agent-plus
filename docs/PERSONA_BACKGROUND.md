# 角色背景知识

在「设置 → 人设 → 角色背景知识 · Markdown」导入或编辑一份 `.md` 文档，然后点击
「单独保存背景」。先保存角色卡，再导入背景；背景按钮不保存其他设置。

文档由管理员编写，描述 **AI 所扮演角色** 的身世、往事、人物关系和世界观。
不是群友档案，不是自动学习的人格成长记忆，也不由模型联网补写。
推荐使用 Markdown 标题划分章节；没有标题也可读取，长章节自动切段。
支持 ATX 与 Setext 标题，代码围栏内的标题不拆段。上限512 KiB、512段。

## 主动查阅

下次唤醒时系统提示只带章节标题与ID（最多40段、5000字符），不展开背景正文。
提示明确要求模型：相关话题涉及自己的过去、关系人物、地点或世界观时，主动调用
`persona_background_lookup`，查过再答；查不到的事实保持未知，普通闲聊不必反复查询。
实际是否调用由模型决定，并非每条消息强制检索。

- 无参数：分页列目录；`offset` 翻页，每页40项。
- `sectionId`：读取目录中对应的正文段。
- `query`：中文/英文关键词检索，标题命中优先。
- `limit`：正文结果1～5项，默认3项；总正文最多6000字符，按 `nextOffset` 继续。

工具只能读取当前轮次角色的背景，无文件路径参数。资料只能补充角色事实，不能更改权限
或系统规则，也不作为现实聊天中已经发生过的经历。没有文档时不提供索引或工具。

## 保存与角色范围

文件位于 `data/persona-background/<角色哈希>.md`。内置卡按 `templateId` 绑定，自定义卡
按角色正文绑定；同一角色跨群、私聊共用，其他角色隔离。按群人设已配置的会话可在下拉
菜单选择，为它实际使用的角色导入资料。仅改机器人名字不换文档；修改自定义卡正文后
视为新角色，旧文档保留，可切回原角色读取。

后台校验角色键与文档修订，冲突返回409，避免另一个标签页或角色切换覆盖文档。
请复制保留冲突草稿再重新加载。UI当前页面内的草稿会在切换分区时暂存，刷新浏览器前
应先保存。替换或清除旧文档前，自动备份到 `persona-background/backups/`。
此目录属于数据目录，随整目录备份；不会因「清除所有记忆、群友印象与消息存档」删除。
清除背景需单独点击并确认，清除后下一次唤醒撤下索引与工具。

## 验证与回退

`node --test test/persona-background.test.mjs test/orchestrator.test.mjs`；浏览器用例
`test/browser/persona-background.spec.mjs` 覆盖导入、保存、重载与清除。
回退代码不删除文档；停用背景可先备份再通过控制台单独清除。已有运行轮次保留其上下文，
背景更新在下一次唤醒时生效。
