# 记忆召回解释与今日功能成本

参考上游 `sakurawwwxh/qq-agent-plus@2e526b3207b89bf3b3990786fcb349df79bc3960`，移植召回解释、来源回合和今日功能成本展示。未引入该提交的群内管理员命令或按人批量删除功能。

会话记忆页的「记忆召回解释与最近使用」只读查询当前角色、当前会话可见的海马长期卡与人格记忆。展示真实保留率、强度、实际使用次数、来源和关键词命中，不把关键词命中伪装为语义评分。语义记忆页另展示其原有检索分项和最多4个来源回合；「最近自动检索」不代表模型实际采用。

检索、展开正文与实际采用分开记录。只有成功 finish 提交的、已读正文的 usedMemoryIds 才算实际使用并按既有频率强化；手动管理查询与仅浏览索引不强化。审计库 `memory-recall-trace.sqlite` 只记录本地元数据，不存正文，最多2000批，每次读取当前会话最近30批。未读取过的旧调用不补猜。该库与遗忘计数库分开，清空及备份随遗忘模块执行。

今日按功能展示聊天、海马消化、人格提取/核验、记忆整理、语义提炼、日报、早报等。沿用当前实际模型和渠道计价、保留 source 原始JSONL台账，辅助调用不会再次算进聊天。包含在途聊天，调用数按模型请求计。旧今日总额无法确定用途的部分归「历史未分类」；表格始终统计今日，不跟随上方多日筛选。未定价调用单独提示。

只读接口：`GET /api/memory/insights?chatKey=group:123&query=关键词`、`GET /api/living-memory/last-recall?chatKey=group:123`。均沿用控制台鉴权，不调用模型。
